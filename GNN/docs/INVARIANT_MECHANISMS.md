# How each model's invariant version is built, and how it maps to the theory

> Companion to `docs/THEORY.md` (the theory as implemented). One section per model; the SlotGAT
> section describes the **parity (upstream-architecture) model** and the SeHGNN section the **relation-aware
> full-K (`full_rel`) flavour**, which are the versions used for the results in `docs/results/`. Code pointers
> are in §7 (paths relative to `models/<MODEL>/` unless they start with `common/`).

## 0. The theory in five lines (THEORY.md §1)

1. A GNN's **structural bias** `S^f` is the set of rooted pattern graphs it aggregates over: per layer
   `h_v ← UPDATE(h_v, TAGG{ PAGG(hom(S^u, G^v), S^u) : S^u ∈ S^f })` — PAGG over the occurrences of a
   pattern rooted at `v`, TAGG across patterns.
2. A **switching** `(P, P′)` rewrites every occurrence of `P` into `P′` (Area on Paper → Area on Conference;
   Director on Movie → Director on the Link copy; a 2-hop path → a named shortcut edge; `r` → `r⁻¹`).
   Two graphs related by switchings are τ-equivalent: same information, non-isomorphic topology.
3. **Lemma 1:** `f` is τ-invariant iff there is an isomorphism-preserving `b_τ : S^f → S^f` such that PAGG
   receives the same input on `G` and `τ(G)`. A fixed `S^f` never satisfies this for every τ (Prop. 4).
4. **Conditional graphs** fix it: each pattern gets *context* edges (must occur) and *propagation* edges
   (carry the message; nodes ⊆ context nodes). `pom` replaces `hom`. The algorithm of Sec. 4.3 extends
   `S^f` to `S_τ^f` in three steps (map the bias through each switching; use switchings as context; map the
   propagation patterns) — τ-invariant (Thm 1), minimal up to isomorphism (Prop. 5), at least as expressive
   (Thm 2). Nodes that are in a context but not in its propagation part are **skip nodes**: they license a
   message but contribute no features (notation `M(L)D`).
5. **Operationally** (THEORY §1.6): the input graph is never rewritten. Per physical variant, preprocessing
   *compiles* the occurrences of every context pattern into a **semantic message program** — the multiset of
   `(src, semantic relation, dst)` propagation messages — which must be hash-identical across variants. With
   identical program + supervision + initialisation + reduction order, training is bit-identical and
   Kendall-τ = 1 **exactly**; that is what every cell in the results tables verifies (identical per-epoch parameter
   hashes and checkpoints across the variants of a seed).

**One amendment: pattern redundancy.** `S_τ^f` can contain τ-equivalent but
non-isomorphic patterns: a pattern and its switched image (on IMDb, every `movie→X` path and its copy
`movie→link→X` through the bijective Link node). Both carry exactly the same information — the switched
image is the pattern with a skip node inserted — so, on any variant, their PAGG inputs are equal after the
skip node is dropped. Message-level models (RGCN, CMPNN, SlotGAT, PathNet) dedupe them automatically: set
semantics on `(src, semantic relation, dst)` messages *is* the quotient. Pattern-parameterised models (MAGNN,
SeHGNN), which allocate parameters and attention per pattern, must take the **quotient** `S_τ^f / ~` explicitly
— one representative per τ-equivalence class, the skip form — otherwise every duplicate costs a channel /
metapath, parameters and attention mass without adding information. τ-invariance (Thm 1) and the expressivity
bound (Thm 2) are unaffected by the quotient, because the dropped patterns are recomputable from the kept ones;
Prop. 5's minimality is read up to τ-equivalence rather than up to isomorphism for these models.

Where the compiled program **equals the union graph** (DBLP, IMDb Movie–Year, WN18RR for RGCN and the SlotGAT LP study by construction — "universal parity" —, MAGNN-intersection on Freebase, SlotGAT Freebase), the invariant arm and the `{model}*` proxy consume the same tensors and are the same function; the cell then shows *exact invariance with per-variant provenance*, and effectiveness is compared against originals and augmentation. ## 2. RGCN — local relation-typed message passing → compiled semantic relations

**Structural bias.** One rooted edge per relation; PAGG = per-relation mean of `W_r h_u`; TAGG = sum over relations. A switching changes 1-hop neighbourhoods, so PAGG's multiset differs across variants (Prop. 3).

**Mechanism.** A **conditional compiler** per dataset turns every context occurrence into a propagation edge typed by the semantic relation; the RGCN then runs *only* on those edges (`common/inv_rgcn/model.py: ConditionalRGCNLayer`, basis-decomposed relation weights shared by **semantic relation name** across variants, `segment_reduce` sums in a fixed dst order).

| dataset | context → propagation (`compile_semantic`) | Sec. 4.3 step it realises |
|---|---|---|
| IMDb | direct `M–X` edges are propagation; the reified context `M–L–X` emits the semantic `M–X` message with Link context-only; the inverse reconstruction `L–M–X` emits `L–X`; the year projects across the bridge except from a held-out target (Movie–Year). Result: for each attribute the four channels `movie/link → X` exist on every variant. | step 1 (bias mapped through the switching: `M–X` and `L–X` both kept) + step 3 (propagation pattern mapped through `p_i` / `p_i⁻¹`) |
| DBLP | `paper→area` reconstructed per variant through the variant's own context (`P→Ar`, `P→C→Ar`, `P→A→Ar`) with a **block-local pair filter** (a shared Conference/Author may carry several areas across paper blocks; only the paper's licensed area is emitted); `conference→area` and `author→area` likewise; Area exists for training-support papers only. | step 2 (the switching pattern as context, propagation `P–Ar` marked inside it), the pair filter keeps `pom` faithful where `hom` would over-generate |
| WN18RR | a catalog of dependencies `q = r₁;r₂;r₃` (mined from the MAGNN universal selections, full catalog = 2,065) defines the semantic relations; per variant the endpoint set of `q` is the direct shortcut edge if the variant materialises it, else the composition of the physical base relations using **virtual transposes** where inverses are absent; the universal variant verifies its physical shortcut equals the reconstruction. 2,087 semantic relations / 893,629 edges = exact parity with the universal graph. | steps 1–3 applied to two switchings at once (`r ↔ r⁻¹` and `path ↔ shortcut`) |
| Freebase | **block-conditional** channels: the relation family = base relations ∪ the registered 2-/3-hop shortcut compositions of {unchanged, exact_2, exact_3}; per source node the endpoint block of each composition is reconstructed from base CSRs one block at a time (physical shortcut edges are provenance/validation only); training samples each block with a deterministic splitmix64 fan-out (4 + 4) keyed on the semantic identity. Catalog `exact_3`: 36 base + the 28 registered compositions = **64 semantic relations / 128 directed channels — exactly the union graph's relation set** (compositions the dataset build rejected by the type-signature filter, which no variant contains, are not part of the family bias and are not compiled). | same as WN18RR, with the composition never materialised as a pair matrix |

**Theory check.** Set semantics on `(src, rel, dst)` is the message-level quotient, so RGCN needs no extra step for pattern redundancy; Lemma 1 holds with `b_τ(S^u)` = the context realisation of the same semantic relation, and the per-relation weights being indexed by semantic name is what makes the learned function identical across variants. Recoverability: on DBLP, Movie–Year and WN18RR the compiled program is the union graph, so `invariant ≡ universal` bitwise per seed. On Freebase the `exact_3` program has exactly the union graph's relations, built by block-conditional reconstruction rather than read from the materialised shortcuts; it is **not** bitwise the universal run: 120/128 channels are byte-identical to the union-graph store, the 4 relations through the self-looped `BOOK-and-BOOK` carry 12,716 extra walk-composed pairs (0.0013 %) that the materialised shortcuts lack, so the program is the union graph plus those pairs (THEORY §6 category 1; test logits differ from universal, max |Δ| 8.6–10.5). Measured: invariant **.6895 ± .0047**, τ = 1 with exact logits on every pair, vs universal .6864, originals mean .6855.

## 3. MAGNN — metapath-instance message passing → skip metapaths on the compiled program

**Structural bias.** Rooted symmetric metapaths (label sequences); the RotatE0 instance encoder ingests *all* nodes of an instance; intra-metapath attention over instances, inter-metapath attention over metapaths. A switching changes which label sequence realises a semantic relation (`M–D` vs `M–L–D`), so the instance multisets differ.

**Mechanism (skip metapaths, compiled).** Skip metapaths are the quotient of §0: an instance is matched on the physical variant *including* the intermediate nodes, but the skip nodes `(X)` are dropped from the stored instance, so variant A's `MDM` and variant B's `M(L)D(L)M` yield the same encoded instance. The v2 compilers (`preprocess_{imdb,dblp}_magnn_v2.py`, `preprocess_freebase_magnn_v2.py`) derive this instead of hand-writing it: a semantic relation's endpoint set in the RGCN bundle **is** its skip-compiled realisation on that variant, so the metapath `C–r→X–r⁻¹→C` over semantic relation `r` is the skip metapath on every variant at once. Instances: each `(c, x, c′)` exactly once (set semantics, canonical order), deterministic cap 500 per (source, metapath) keyed on `hash(seed, metapath, source)`; long forms (`M–L→X–L⁻¹→M`, `P–A→Ar–A⁻¹→P`, Freebase `B–r₁→X–r₂→Y…`) drawn by an exact hierarchical sampler over the step matrices with interior nodes real.

| set | what it is | theory |
|---|---|---|
| **intersection** (`invariant`) | one metapath per semantic relation incident to the target: the skip form (IMDb `MDM MAM MLM MYM`; DBLP `PAP PTP PVP PArP` + `VPV VPAPV`; Freebase 26 `BOOK–r→Y–r⁻¹→BOOK`). | `S_τ^f / ~` — the canonical bias; same capacity as the original model on the canonical variant (§0, pattern redundancy) |
| **union** (`invariant_union`) | intersection + the long forms whose interior nodes are real on every variant (IMDb `MLDLM MLALM MLYLM`; DBLP `PAArAP PVArVP`; Freebase 18 long forms). | `S_τ^f` itself — strictly more expressive where the interior node carries information (Thm 2's "sometimes strictly more"); on DBLP it is the set that matters (+8 MRR points), because the query's own area edges are masked and the Area switching reaches the query only through `PAArAP` |

Why a naive Freebase metapath extraction gives τ ≠ 1 (and the v2 compiler does not): without collapsing interior witnesses, `(b, c, b′)` appears `k·k′` times on `unchanged` but once on `exact_2`, and a per-start cap (e.g. 1000) that truncates by physical adjacency order selects different instances per variant — both violate THEORY §5. LP: the query edge, its alias copy (Link) and the head's label-derived metapaths are masked for every candidate, so a training query's instance sets look like a held-out query's.

**Recoverability.** `stock/universal` and `invariant_union` compile to the same program (DBLP `3c530196…`, Movie–Year `d571cfbafb`); on Freebase `stock/universal` equals the *intersection* `invariant` program (`9fa90f3c…`; `invariant_union` is `d694b523…`), and `stock/v1` equals `invariant` where v1's physical set is the intersection set — so on those cells the invariant model is bitwise the universal / the v1 original.

## 4. CMPNN — source-conditioned path propagation → the same semantic program, per query

**Structural bias.** For a query `(h, r, ?)`, rooted relational paths of length ≤ L from `h` (Bellman-Ford iterates of NBFNet / C-MPNN): per layer PNA over the multiset of incoming `(src, rel)` messages, DistMult relation messages, the query as boundary condition. A switching changes the path set from `h` (inverse edges create paths, shortcuts shorten them, extra hops lengthen them).

**Mechanism.** No compiler of its own: CMPNN consumes the **forward half** of the RGCN semantic program (`inv_cmpnn/bundles.py`; `X_to_Y` kept, `Y_to_X` dropped because `undirected(add_inverse=True)` adds inverses itself — otherwise every fact would appear twice under two labels; on WN18RR the `inverse::` relations are dropped **and the `dependency::` shortcuts too** — `run_cmpnn_lp_wordnet_context.py` keeps the 11 `base::` relations only, see below). Why a *global* identity is enough for a query-rooted model: the subgraph Bellman-Ford explores is a function of the global edge list and the query, so identical labelled edge multisets ⇒ identical rooted path sets for every `h` ⇒ identical PNA inputs at every node and layer ⇒ identical scores. Two things the theory requires that the stock model does not provide: (i) **multiplicity** — PNA's mean/std and `log(degree)` scale see counts, so the program's set semantics (no duplicate `(src, dst, rel)`) is essential; (ii) **determinism** — `torch_scatter`'s atomic sums are order-dependent, so the invariant runner sorts edges by `(dst, rel, src)` and reduces with `segment_reduce` (chunked on WN18RR).

`remove_easy_edges` is extended so the training query's edge leaves the graph together with its derived copies: `(alias(h), t)` on IMDb (Link carries `link_to_director` for training pairs) and `(h, *, paper_to_area)` on DBLP (`paper_to_area` exists for training papers only — after masking only the direct edge, `paper → area → conference` reached the answer for 100 % of training and 0 % of held-out queries). The validation checks the ≤ 2-hop reachability of the true tail for masked training vs held-out queries.

**WN18RR: shortcuts and inverses as context only.** The 2,065 shortcut relations are mined from the training graph, so every training triple leaves derived copies of itself (`(h, q, z)` with `q = (r, r₂, r₃)` and `z` two hops past `t`) that the exact-triple mask does not remove — the DBLP defect above on 2,065 relations at once: the leak audit found a shortcut consistent with the true tail for 96.9 % of training queries vs 35.3 % of held-out ones, so a program that propagates over the shortcuts lets training queries see their own answer. For a path model the `path ↔ shortcut` and `r ↔ r⁻¹` switchings are already inside `S^f` once inverse traversal is virtual (`add_inverse`): the chain carries the propagation, the shortcut is context (its equality with the chain is the compiler's audit). The invariant program is therefore the **11 base relations** — hash-identical on all four variants and byte-identical to the `no_changes` physical graph — and the invariant arm reproduces the `no_changes` original bitwise on every variant and seed (**.4238, τ = 1**).

**Theory check.** `S^f` is the set of rooted paths, `b_τ` maps a path on `G` to the path on `τ(G)` with the same semantic relation labels; the compiled program makes those label sequences identical. Recoverability: DBLP and Movie–Year `invariant ≡ universal` bitwise; Movie–Director is the one IMDb LP cell where the program is a strict superset and the invariant arm beats the proxy; WN18RR `invariant ≡ the no_changes original` bitwise (the union graph is not the reference there, being leaky under the stock mask).

## 5. SlotGAT (upstream / parity architecture) — typed-slot attention → conditional message plans

**Structural bias.** 1-hop typed edges; every node keeps one feature slot per node type, a neighbour's features land in the slot of its type, attention combines slots (`l2byslot` readout, slot attention, projected residuals, attention residual α = 0.05 in the upstream model). A switching re-routes which slot receives which features and adds/removes slots (Link, Area).

**Model.** `model/parity_slotgat.py` is a port of the upstream `slotGAT` onto a **plan-driven, deterministic** operator (degree-bucket / segment softmax instead of DGL's atomics): same computation as upstream to float precision (verified with copied weights; parameter counts equal), so the original, universal, augmentation and invariant arms are one architecture. The invariant version changes only the *plan* the operator receives.

**Mechanism.**

| dataset | plan | what the attention normalises over |
|---|---|---|
| IMDb | **raw-context conditional plan** (`conditional_bias.py`): each variant keeps its own raw typed edges and the concrete context witnesses found in it; at forward time direct `Movie–Role` contexts and two-hop `Movie–Link–Role` contexts are mapped to the same semantic propagation events, typed by the semantic relation (15 edge types), each attribute role projected onto both endpoints of the Movie/Link pair. Per variant 50,142 raw context edges → 107,713 semantic messages, identical program hash. | the same typed message multiset on every variant |
| Freebase | **recoverability-conditional plan** for the family {unchanged, exact_2, exact_3}: one channel catalog (129 channels = base relations ∪ registered 2/3-hop compositions, one program hash), a context plan per variant (base CSRs + 420,063 conditional path records; physical shortcut edges are provenance, validated against the registry), and the **union-message schedule**: one message per ordered `(dst, channel, src)` record, reproducing the direct records of the union graph, its generated missing-reverse records and self records, without ever materialising endpoint-pair matrices for the dense compositions. 750.5 M messages for every invariant run (the same schedule the universal arm uses). | the same incoming records as the union graph (rather than replacing a shortcut neighbourhood by a factorised path aggregate, which would change the normalisation) |

**Theory check.** The block-conditional pattern is the context (`B→X→Y` composition), the propagation edge is the typed endpoint pair; Lemma 1 holds because the slot / edge-type identity of each message is the semantic relation, not the physical one. The witnesses that differ per variant affect derivation and validation, never computation. Recoverability: on IMDb the compiled plan equals the union graph plus self loops (measured, zero difference either way), but the universal row is the parity model on the union graph's *physical* schedule (.6519), whose message typing is physical rather than semantic, so universal ≠ invariant on this cell (THEORY §6 category 3); on Freebase the invariant schedule *is* the union schedule; the invariant arm therefore shows exact invariance with per-variant provenance, and the honest effectiveness comparison is against the originals and augmentation. Message-level dedupe = the quotient at message level; channel identities are not quotiented (a smaller version of the SeHGNN redundancy, noted, not measured).

### 5a. SlotGAT link prediction

The SlotGAT LP model is the **deterministic parity SlotGAT on the RGCN structural bundles**: the upstream `slotGATConv` ported onto a sorted edge list with `segment_reduce` edge softmax (no atomics), slots = node types on IMDb / DBLP (`lp_parity_hetero_model.py`) and one slot on WN18RR (`lp_parity_model.py`), concat-of-layers + LayerNorm readout, diagonal DistMult decoder, `neg_logsigmoid` objective as the other models. Same four arms and inputs as RGCN / CMPNN: physical edges for originals / universal / augmentation, the compiled semantic program for the invariant arm (IMDb `_v10_year_canonfeat`, DBLP `_v8_dblp`, WN18RR `universal_parity_full` — the full 2,087-relation program, unmasked, since the 256-negative contract does not need the mask there); IMDb / DBLP use `--mask-batch-edges` (query edges both ways, Link alias copies, `paper_to_area` of the batch heads). Validation: physical hashes differ → semantic message hash identical → per-evaluation parameter hashes identical → final checkpoints identical → spread 0, τ = 1 — holds on every cell. Recoverability: Movie–Year and DBLP `invariant ≡ universal` bitwise (.2171, .5565); Movie–Director differs (program ⊋ union, .2514 vs .2610); WN18RR the message *typing* differs (universal physical vs semantic — THEORY §6 category 3; .3662 vs .3635).

## 6. SeHGNN (relation-aware full-K, `full_rel`) — pre-computed metapath channels → channels over the semantic relations

**Structural bias.** Before training, one feature channel per type path `T₀→T₁→…→T_k` of length ≤ K from the target type: the nested mean `rownorm(A₀₁)·rownorm(A₁₂)⋯·X_k` (Freebase: a sparse selector over learned per-type embeddings); the channels are projected, fused by a transformer over the channel axis and classified. PAGG is the nested mean over the path's occurrences, TAGG the transformer. A switching changes which type paths exist and each path's occurrence multiset.

**Mechanism.** The same channel operator is applied to the **compiled semantic relations** instead of the physical ones (`preprocess_sehgnn_channels.py --graph semantic`): a channel is a product of relation-step matrices along the semantic realisation of the path, so its tensor is a deterministic function of the program and is bit-identical across variants; the model is untouched. Two design choices define the flavour used here:

1. **Relation-aware steps (`full_rel`).** Stock SeHGNN enumerates paths over the *type-collapsed* adjacency, merging every relation between the same endpoint types into one step. This matters only on Freebase (one relation per type pair on IMDb; up to 9 on Freebase's `(BOOK, MUSIC)`, plus the directed `BOOK-and-BOOK` symmetrised): there it would merge `MUSIC-in-BOOK` (31 k pairs) with `BOOK-about-ORG-to-MUSIC` (44 M) and `…-and-MUSIC` (234 M) into one (BOOK, MUSIC) channel, and with 500 sampled walks the base relation's neighbours would be drowned. `full_rel` gives every semantic relation its own step: K = 2 paths over the 64-relation family catalog → 597 channels on the program (91 / 159 / 443 on the physical variants). **The invariant arm keeps the 511 of those channels that occur in at least one variant's own stock bias** — Sec. 4.3 step 1, each variant's `S^f` mapped through the switchings, i.e. `S_τ^f` proper — and does not add the 86 `2-hop ∘ 3-hop` composites that no variant's bias contains. The universal arm is stock `full_rel` on the union graph (597): it has no per-variant biases to take the union of. Theory: Prop. 5's minimality is "no two *isomorphic* conditional graphs" — collapsing non-isomorphic patterns (different relation labels) into one channel destroys exactly the distinction the bias is supposed to keep.
2. **Skip types are neither a step nor a feature source.** On IMDb the semantic program contains, for every `movie→X`, its switched image `link→X`; enumerating type paths over all of it would produce many exact duplicate channels (every path through the Link copy equals the path without it), each paid for in parameters and attention. The invariant arm therefore takes the quotient of §0: enumerate the stock bias over the canonical schema {M, D, A, Y} realised on the semantic relations, with the skip type excluded — 25 channels + 13 label channels (the 21 distinct feature matrices of every variant), program `8e48cd229f7e` on all four variants; invariant `full` .6535 vs universal .6431, +.5 pt over the proxy in 7/10 seeds. This is THEORY §2.4's "skip feature injection at skip nodes" made exact.

Other contract points that are part of the invariance argument: Freebase channels are capped at 500 walks per (target, channel) by a seeded k-stage uniform sampler (an unbiased estimate of the nested mean, keyed on the semantic identity, identical in every arm); IMDb label channels drop the node's own label (the rule of the SeHGNN paper; the upstream runner leaks it); per-type input projection so parameter count does not scale with the channel count.

**Theory check.** Channel = PAGG over `pom(S^u, ·)` for the path pattern `S^u`; `b_τ` maps a type path to its realisation over the same semantic relations. Recoverability: on Freebase the program's relation set equals `union_exact_2_3`'s, but the 511-channel invariant arm is the union of the variants' biases rather than the union graph's full 597-channel enumeration — a different computation from the universal arm, as on IMDb; on IMDb the program is a strict superset and the invariant channel set (25) is smaller than the union's (101) — the quotient, not the union.

## 6a. PathNet — MERW walks → the same sampler on the compiled program

**Structural bias.** Per target node, maximal-entropy random walks (40 walks × length 4, a fresh set every epoch) with each walked node bucketed by its exact BFS distance to the target; an LSTM reads each walk, a gated mean aggregates the walks (upstream `PathNet_homo`), and the result is concatenated with the ego representation. A switching changes the adjacency the walks are drawn from, hence the walk multiset.

**Mechanism.** The invariant arm runs the unchanged sampler (RNG keyed on (seed, epoch)) on the undirected 0/1 adjacency of each variant's compiled semantic program — the RGCN year bundle on IMDb, the Freebase family program `exact_3` (64 relations) — instead of on the physical graph. The programs are hash-identical across variants, so the walks, and therefore training, are identical: τ = 1 with identical checkpoints. Set semantics on the program's edges is the message-level quotient, so no pattern-level step is needed. Details and results: `models/PathNet/README.md`.

## 6b. PAIN — rooted simple paths → the same enumeration on the compiled program

**Structural bias.** Every rooted simple path with up to L = 3 edges (exhaustive on IMDb; on Freebase a sample of 4 relations / fan-out 8 / cap 256 per root). Each path becomes a sequence of (node feature, positional encoding, edge-type embedding, neighbour mark) read by an LSTM; the encodings are summed at the root, followed by a residual MLP layer. A switching changes which simple paths exist, hence the rooted path multiset.

**Mechanism.** Each variant's own graph is compiled into a semantic program, and the unchanged path enumeration runs on it. IMDb (`build_imdb_invariant_minimal.py`): the switched director / actor relations are carried by conditional edges; the program is identical on v1–v4 (semantic hash `9825cee1bec6`, path program `f0c474c9df47`, 11.2 M paths). Freebase: the family program (`preprocessing.freebase_invariant`), every composition rebuilt from the variant's own base relations; the path sampler is keyed on semantic identity (stable rank of (seed, src, dst, semantic type) over a sorted adjacency), so the sampled path program is identical on all three variants (`4f27282d6b2f`). The model, loss and protocol are unchanged. Details and results: `models/PAIN/README.md`.
